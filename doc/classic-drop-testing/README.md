第一条运行实际 React 生命周期、React Router 和 Zustand 集成回归；第二条在临时源码副本中逐项撤掉关键修复，确认对应行为断言会失败。消融不修改工作区业务代码。基线固定为修复前的 `e0ff7a8`，可通过第二条命令的首个参数指定其他已有提交。

## 测试覆盖与边界

保留真实引导页、批量布局、列表页、导入解析、压缩状态库和导航 hook；运行真实 React `useEffect` 挂载与清理。覆盖连续图片/视频导入、原有压缩进度及成品状态保留、重复路径、压缩中追加待处理项、快速导入、解析失败恢复、切换模式与重新进入、迟到订阅清理、离开页面后的迟到解析、清空批次后的迟到 / 排队导入、旧对话框回调失效，以及目录展开后排除已有视频。视频失效测试同时断言原生任务没有被登记，避免只有界面丢弃结果、底层仍产生任务。

Tauri 原生事件及文件元数据、系统对话框、遥测、视觉末端组件与视频任务事件使用适配器。该集成测试不进行真实视频编码，也不替代 macOS Finder 原生拖放验收；本目录消融结果仅声明上述集成测试范围。

完整 Node/Rust 回归、生产构建、原生导入与压缩、Finder 验收边界见 [完整测试与原生验收记录](verification.md)。

2026-10-28，用户使用其他素材实际拖入并反馈测试通过；原生拖放人工验收已补齐。该结论依据用户反馈，未额外声称观察到指定临时素材的卡片数量。

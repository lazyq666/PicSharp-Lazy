# PicSharp-Lazy

基于 [AkiraBit/PicSharp](https://github.com/AkiraBit/PicSharp) 的个人修改版。这里只记录与原项目的区别，原有功能和使用说明请参考原项目。

## 与原项目的区别

- **新增视频压缩**：图片与视频可混合批量导入，也可通过目录监听自动处理。提供「更小体积」「画质均衡」「广泛兼容」三档预设，全部在本机处理，统一另存为 MP4 并保留原片；支持进度显示、取消、重试和历史记录。暂不支持 HDR 视频。

- **改进目录监听**：等待文件写入稳定后再处理。图片压缩后，用户修改图片并以同名文件覆盖到监听目录，仍会识别内容变化并再次压缩。已登记成品在改名、同一磁盘内移动或应用重启后仍可识别，减少重复和循环压缩；局部文件出错时，提示具体路径并继续处理其他文件。

- **加强保存与撤销保护**：保存结果及撤销压缩前核对文件身份和版本，避免旧任务覆盖或误删后来导出的新稿。

- **新增 .9 图片忽略开关**：监听时默认跳过 `button.9.png` 这类九宫格图片，可在设置中关闭。忽略规则支持 `*.png`、`**/draft/**` 等通配写法。

- **修复连续拖入**：首次导入后可继续拖入图片、视频或文件夹，追加到当前列表，保留已有进度和结果，并过滤重复路径。

- **独立 Mac 发布与更新**：提供 Apple Silicon 和 Intel 两种 Mac 安装包，要求 **macOS 26 或更新版本**。内置图片处理服务和视频引擎，无需另装依赖；使用 ZIP 安装包，应用更新仅来自本仓库。首次从原版迁移时，需手动安装本分支版本。
